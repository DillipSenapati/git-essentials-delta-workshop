# git-essentials-delta-workshop

## Essential commands for this practice

1. Clone the repo

```bash
git clone https://github.com/imr-framework/git-essentials-delta-workshop.git
```

2. Create a branch

```bash
git switch -c feature/{name}
```

3. Make any planned changes

4. Add (stage) your changes
```bash
git add {file_name}
```

5. Commit changes
```bash
git commit -m {Add message}
```

6. Push to git
```bash
git push --set-upstream feature/mr_experiment
```

7. Do a Pull request
